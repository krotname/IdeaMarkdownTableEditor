# Мониторинг дешёвой DDR4 ECC REG памяти для X99

Скрипт следит за Wildberries, Ozon, Авито и Яндекс Маркетом и присылает в
Telegram новые предложения серверной DDR4 (ECC REG / RDIMM — то, что нужно
китайским платам X99), которые **дешевле рынка**: цена за гигабайт ниже
порога из `config.yaml` или на 25%+ ниже медианы текущей выдачи. Повторно
одно и то же объявление не присылается (память — в `state.json`), кроме
случая, когда цена упала ещё сильнее.

## Ориентиры цен (август 2026)

|---|---|---|---|

| Ozon | Atermiter 2×16 ГБ 2133 ECC REG | ~9 700 ₽ | ~302 |
| Я.Маркет | Samsung 16 ГБ 2133 Reg ECC (новая, «белые» продавцы) | от ~9 200 ₽ | ~576 |
| Сервер-магазины | Hynix 16 ГБ 2133 (HMA42GR7MFR4N-TF) | ~3 500 ₽ | ~219 |

Отсюда пороги по умолчанию: **220 ₽/ГБ** глобально и **160 ₽/ГБ** для
Авито. DRAM с конца 2025 дорожает — пересматривайте пороги.

## Установка

```bash
cd scripts/x99-ram-monitor
python3 -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium                      # для Ozon/Авито/ЯМ
```

Telegram: создайте бота у [@BotFather](https://t.me/BotFather), узнайте свой
chat id у @userinfobot и экспортируйте `TG_BOT_TOKEN` и `TG_CHAT_ID`.

## Запуск

```bash
python monitor.py --selftest              # проверка логики, без сети
python monitor.py --once --dry-run        # разовый проход, только консоль
python monitor.py --once                  # проход + телеграм + state.json
python monitor.py --loop 1200            # постоянный мониторинг (20 мин)
python monitor.py --once -m wildberries   # только один маркетплейс
```

Постоянный запуск — через `crontab.example` или `--loop`.

## Антибот

* **Wildberries** ходит обычным HTTP-запросом в открытый поисковый JSON —
  браузер не нужен.
* **Ozon и Авито** при первом запуске могут показать проверку. Поставьте в
  `config.yaml` `headless: false`, пройдите проверку руками один раз —
  куки лягут в `.profiles/…`, дальше работает headless.
* **Яндекс Маркет** капчует агрессивнее всех, поэтому выключен по
  умолчанию (`markets.yandex_market.enabled: false`).

Не опускайте интервал ниже 10–20 минут и не раздувайте список запросов:
это и вежливо по отношению к площадкам, и снижает шанс бана. Скрипт — для
личного мониторинга цен; коммерческий парсинг маркетплейсы запрещают.

## Что считается «памятью для X99»

Фильтр в `config.yaml`: заголовок должен содержать `ddr4` и хотя бы одно из
`ecc / reg / rdimm / сервер`, и не содержать `ddr3 / ddr5 / sodimm /
ноутбук / материнская`. Обычная десктопная (non-ECC UDIMM) память тоже
запускается на части плат X99, но смысла в ней нет — серверная REG сильно
дешевле за гигабайт. Для Xeon v3/v4 берите 2133/2400 МГц: контроллер выше
всё равно не разгонит.
