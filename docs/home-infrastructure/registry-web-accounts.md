# Реестр личных кабинетов и веб-админок

Всё, куда можно зайти браузером. Паролей здесь нет — в колонке «Секрет» стоит ссылка на запись
в менеджере паролей, правила описаны в [README](README.md).

Плейсхолдеры: `<логин>`, `<IP>`, `<хост>`, `<провайдер>` заменяются своими значениями,
`—` означает «не заполнено» или «не применимо».
